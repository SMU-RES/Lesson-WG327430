## 课程简介

本课程为上海海事大学自动化专业本科阶段的集中实践课，上课地点为物流 336（PLC 实验室）：

- **班级安排**：自动化两个班在同一间教室一起上课。课程周期共 3 周，课表上排课为每周 2 天，实际通常按每周 3 天开展。
- **分组与选题**：两人一组。开课时老师会给出一批题目，每组从中选一个完成。本项目实现的是“汽车系统”题目。
- **硬件与联动要求**：每组需要占用两台 PLC、两台变频器/伺服（G120 或 V90，需要带动两台电机）以及 HMI 触摸屏；两台 PLC 用网线互联实现双机联动（单台设备网口数量不够，必须用两台）。
- **仿真方式说明**：做流水线类仿真，老师推荐使用 Factory IO；本项目没用 Factory IO，而是自己画了一个 3D 模型来仿真。
- **成绩评定**：不设笔试，以答辩方式结课。答辩在最后一周（第 3 周）的最后一天进行。

## 课程要求与流程要点

### 设备占用与分批使用

- 每组要占用两台 PLC、两台变频器/伺服等设备，设备总量是绝对不够用的，因此需要分批次使用，注意现场设备的使用情况。
- 如果下一届人数变多，老师也有可能直接分班，那样设备或许就够用了。
- 网线也可能不够用，需要时找老师要。

### 设备网口位置

- **G120 变频器**：网口在机器下方。
- **V90 伺服驱动器**：网口在机器顶部，翻开盖板就能看到。

### 设备 IP 配置建议

- **逐台单独配置**：每次只连一台设备，配好确认后再配下一台。
- **统一复位检查**：所有设备都单独配好后，再全部接好、统一复位一遍。

### 考勤（2023 届情况）

- 每天上午、下午上课前都要在教室前排签到；只有签到，不点人头，也不卡签到时间。

### 答辩与提交

- 成绩以答辩代替考试：给老师简单讲一下你做的项目，老师会问一些问题。
- 完成后需要在学习通提交源代码和程序等内容，注意不要忘记提交。

## 使用建议（AI 与 Openness）

- **上位机开发**：C# 上位机部分可以直接用 AI 辅助编写，效率很高。
- **TIA Portal Openness**：西门子博途有 TIA Portal Openness（常简称 opens），可以用代码直接实现包括设备搜索在内的各种功能。
- **调试终端选择**：只要电脑有网口，就可以用网线直接连到自己的电脑上操作；也可以用实验室电脑，但那边是 Windows 7 系统，体验不一定好。
- **工程复用**：如果选到类似题目，可以直接参考“content/上位机工程”的程序改造使用。
